# 👋 maxioo21

## 📍 Odkrywaj
Aplikacja na telefon: atrakcje, jedzenie, baseny i inne miejsca w każdym mieście i wokół Ciebie, z mapą i nawigacją.

📲 **Pobierz na Androida (APK):** https://github.com/maxioo21/maxioo21/releases/latest/download/Odkrywaj.apk

👉 **Otwórz w przeglądarce:** https://maxioo21.github.io/maxioo21/odkrywaj/

Na Androidzie: Chrome → ⋮ → „Zainstaluj aplikację”. Na iPhonie: Safari → Udostępnij → „Do ekranu początkowego”.
